## 🌟 核心特性

### 1. 实景魔方录入与 AI 手把手慢速教学（核心重点）
- **手持坐标系基准引导**：严格对齐「白色中心朝上 ⬆️，绿色中心正对自己 👀（右侧为红，左侧为橙，底面为黄，背面为蓝）」，彻底杜绝转晕。
- **双视图实时双向同步**：
  - **中央 3D 交互区**：点选任意贴片即时涂色，悬停光线拾取高亮，支持拖拽自由旋转及 6 面快捷对齐（顶/前/右/底/左/后 + 一键回正标准视角）。
  - **2D 十字展开图（Net Editor）**：标准的 `U / L-F-R-B / D` 展开图，每个小格标明方位，与 3D 毫秒级双向同步，异常格子红框闪烁警告。
- **5 重物理合法性严格校验（`cubeValidator.ts`）**：
  1. **完整度校验**：检测是否存在未涂色的空格。
  2. **颜色数量校验**：6 种颜色每种严格等于 9 块，不等时明确指出多涂/少涂数量。
  3. **角块与棱块物理存在性校验**：检测 8 角块与 12 棱块是否为合法物理块且互不重复（严禁对立色同块）。
  4. **朝向守恒校验**：角块朝向和满足 $\sum \text{co} \pmod 3 = 0$；棱块朝向和满足 $\sum \text{eo} \pmod 2 = 0$（拦截单个角块被拧转或单个棱块装反）。
  5. **置换奇偶校验**：角块排列逆序奇偶性与棱块排列逆序奇偶性满足 $(p_{\text{corner}} + p_{\text{edge}}) \pmod 2 = 0$（拦截单对块互换非法错位）。
- **两阶段 Kociemba 最优求解器（Web Worker）**：
  - 在独立 Web Worker 中运算，主线程零卡顿，对任意合法状态计算出平均 18–22 步最优解。
- **大白话中文手法指南与 3D 空间动态指引**：
  - 将 Singmaster 记法精准翻译为中文手势指南（如 `R: 右侧面 · 向上推 90°`，`U': 顶层 · 向右拧 90°`）。
  - **3D 发光高亮即将旋转的目标层 9 个小方块**，并动态渲染**发光 3D 弧形方向箭头**指向实际旋转方向。
- **完全跟手的节奏控制台**：
  - **单步慢速执行**（默认 0.6x，约 450ms），执行后停留在新状态供核对手中魔方。
  - **重播当前步**（快捷键 `R`）、**回退上一步**（快捷键 `←`）。
  - **自动跟练模式**（可调停顿间隔 1.5s / 3s / 5s）。
  - **横向公式胶囊进度轴**与**通关礼花庆祝弹窗**。

### 2. 20 关固定闯关模式
- **4 大章节由浅入深**：
  - **第一章 · 新手启蒙 (Lv.1~5)**：一步入门、双轴联动、顶层归位、Sexy Move 黄金四步、五步小试。
  - **第二章 · 进阶公式 (Lv.6~10)**：十字破局、小鱼一式 Sune、棱块三循环 Ua-Perm、8步限步挑战、极速60秒限时赛跑。
  - **第三章 · 花式图案 (Lv.11~15)**：国际象棋盘、六面回字、十字圣徽、魔方中的魔方、蟒蛇盘绕。
  - **第四章 · 大师试炼 (Lv.16~20)**：14步深度迷宫、45秒极速挑战、15步严格限步、Superflip（全12棱原地翻转）、WCA 20步传奇宗师。
- 支持三星评定、进度本地存档、「AI 提示下一步」与「切换 AI 教学演示」。

### 3. 随机竞速与自由探索模式
- 入门(6步) / 标准(12步) / WCA(20步) 打乱生成器。
- 一键生成 7 大世界级艺术图案（棋盘、六面回字、十字、魔方中的魔方、蟒蛇、条纹、Superflip）。
- 0.01s 精确 WCA 计时器（空格长按准备/松开启动，还原自动停止判定）。
- 实时计算 TPS（每秒转速）、PB（个人最佳记录）与历史成绩存档。

### 4. 纯代码合成音效（Web Audio API）
- **零外部音频静态资源依赖**：
  - 磁吸机械手感声效（双层拟真物理撞击）
  - 涂色轻点音
  - 华丽大九度通关琶音和弦
  - 错误警示音与静音切换

### 5. 4 套精心调校的配色主题
- **WCA 竞速经典**（实景录入默认基准，与实物颜色高度吻合）
- **赛博霓虹**（电光青、荧光绿、品红、冰紫）
- **莫兰迪柔光**（鼠尾草绿、灰粉红、陶土橙、板岩蓝）
- **极光磨砂**（极地白、翡翠极光、北极天蓝、日冕橙）

## 🛠️ 技术栈与架构设计

- **框架**：React 18 + TypeScript + Vite + Tailwind CSS + Lucide React
- **3D 引擎**：原生 Three.js
  - `CubeEngine.ts`：负责渲染、拾取、动画队列、四元数正交吸附与 3D 教学指引箭头。
  - `RoundedBoxGeometry`：圆角立方体与高光清漆贴片。
  - `RoomEnvironment`：程序化 PBR 环境光反射。
- **群论算法**：`cubejs`（两阶段 Kociemba 算法，运行在独立 Web Worker 中）。
- **音频系统**：Web Audio API 程序化合成。
- **自动化测试**：Vitest（32 项全量闭环测试用例）。

## ⌨️ 快捷键速查

| 按键 | 功能说明 |
| :--- | :--- |
| `1` ~ `6` | 涂色模式下快速选择颜色（白、红、绿、黄、橙、蓝） |
| `0` / `E` | 涂色模式下切换至橡皮擦 |
| `Space` / `→` | 教学模式下执行下一步演示；自由模式下启动/停止计时器 |
| `R` | 教学模式下慢速重播当前步 |
| `←` | 教学模式下回退至上一步 |
| `U / D / L / R / F / B` | 游戏模式下顺时针旋转对应面（按住 `Shift` 逆时针） |

## 🚀 本地开发与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 运行全量 Vitest 单元测试
npm run test

# 4. 执行生产打包与类型检查
npm run build

# 5. 本地预览生产构建产物
npm run preview
```
